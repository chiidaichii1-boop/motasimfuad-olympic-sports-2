One funny single-line sport the Olympics turned down, judged by a house AI on pure laughs.

Bounty: https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da

## The entry

`main.py` (Python standard library only) writes exactly one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Synchronised Sighing: four athletes sigh in perfect unison at a delayed train announcement — gold for the deepest collective disappointment.

## Run it

```sh
python3 main.py
```

The output directory is read from `MAKEFUN_OUTPUT_DIR` (default `/output`).
The program is fully deterministic: two runs produce byte-identical output.
